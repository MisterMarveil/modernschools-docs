<Procedure>
<Step title="Open class groups">

**Settings → Structures → Class groups**. The list shows each group's **parent group** and **child groups**.

<DocScreenshot src="web/structure/class-groups" alt="Class groups list with parent and child groups" />

</Step>
<Step title="Add">

Click **Add** (top right), name the group (in French and English), choose its **parent group** (for example *2nd Cycle* for an upper-secondary level), then **Create**.

</Step>
</Procedure>

<ExpectedResult>

The group appears in the list under its parent; it can now hold classes.

</ExpectedResult>

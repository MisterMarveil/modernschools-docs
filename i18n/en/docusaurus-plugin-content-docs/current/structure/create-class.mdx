<Procedure>
<Step title="Open the form">

**Settings → Structures → Classes → Add**.

</Step>
<Step title="Fill in the class">

<DocScreenshot src="web/structure/class-create" alt="Class creation form">
  <Hotspot number={1} x={16} y={21} label="Class group" />
  <Hotspot number={2} x={24} y={38} label="Name" />
  <Hotspot number={3} x={16} y={43} label="Default language" />
  <Hotspot number={4} x={24} y={52} label="Exam code" />
</DocScreenshot>

1. **Class group**: the level the class belongs to.
2. **Name** (required): for example *6eme B*.
3. **Default language** (required): French or English.
4. **Exam code**: optional, used by exam photos.

The **automatic detection of unclassified students** box is ticked by default.

</Step>
<Step title="Save">

Click **Create**, **Create and return to list** or **Create and add another**.

</Step>
</Procedure>

<ExpectedResult>

The class appears under **Classes** with its group and language.

</ExpectedResult>

:::tip
To create several classes with their subjects at once, use the [initial setup](/structure/initial-setup) instead.
:::

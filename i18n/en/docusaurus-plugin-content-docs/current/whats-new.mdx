## Version 2026.11.14

- **One profile at a time**: each page opens under the profile chosen after signing in; a page of another profile explains why it is closed. See [roles and access](/users/roles).
- **Accounts limited to class groups** (head of studies, discipline officer), checked on every action.
- **Passwords**: no password typed when creating an account; **Reset password** button; default passwords published.
- **Discipline**: entry page reorganised, sanction suggested from the grid. See [enter discipline information](/discipline/enter-info).
- **Messages to families** (WhatsApp, e-mail), enabled school by school. See [write to families](/discipline/messaging).
- **Security**: every page and the API now require signing in.

## Release 2026.11.7

- **Student photos by batch**: ZIP organised by class, review gallery, explicit validation, can be cancelled. See [import student photos](/students/photos).

## November 2026 — official website

- **Find my school**: search published schools and open the current year's space directly. See [find my school](/getting-started/find-school).
- **Online registration** of a new school, with file tracking. See [register a new school](/onboarding/new-school).

## Initial setup

- Classes, subjects, coefficients and periods created from a template; student and teacher imports checked before writing. See [initial setup](/structure/initial-setup).

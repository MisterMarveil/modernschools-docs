## Versions 2026.11.16 and 2026.11.17

- **Report cards**: the letterhead is more compact and carries the instance's school year, archives included. See [generate report cards](/documents/report-cards).
- **Grade entry status**: the **Notify** button goes through the school's messaging and says clearly when it is not enabled yet; screen translated into English. See [track grade entry](/analytics/grade-entry-status).

## Release 2026.11.7

- **Student photos by batch**: ZIP organised by class, review gallery, explicit validation, can be cancelled. See [import student photos](/students/photos).

## November 2026 — official website

- **Find my school**: search published schools and open the current year's space directly. See [find my school](/getting-started/find-school).
- **Online registration** of a new school, with file tracking. See [register a new school](/onboarding/new-school).

## Initial setup

- Classes, subjects, coefficients and periods created from a template; student and teacher imports checked before writing. See [initial setup](/structure/initial-setup).

Imports are checked **as a whole**: at the slightest error, nothing is saved and each faulty row is listed. Fix the file, then click **Contrôler sans importer** (check) again.

| Message | Fix |
|---|---|
| Unknown class | choose the class from the template's drop-down; do not type it |
| Empty required field | students: class, surname, first name, sex; teachers: name, subject, classes |
| Invalid date | DD/MM/YYYY format, for example 05/09/2014 |
| Invalid sex | M or F |
| File too large or unreadable | .xlsx or .csv, 5 MB at most; start again from the downloaded template |

:::tip
Always start from the **template downloaded from your school**: it contains your exact classes and subjects.
:::

ModernSchools refuses to save a student whose **surname and first name** match those of an existing student.

1. **Look for the existing student**: **Students → Filters**, by surname. If it is the same student, edit their record instead of creating a new one, for example to [change their class](/students/change-class).
2. **Two different students share the same name**: complete the first names as on the birth certificate (a middle name, for example). The matricule will then tell them apart on every document.

During an import, students already present are simply skipped: see [import several students](/students/import).

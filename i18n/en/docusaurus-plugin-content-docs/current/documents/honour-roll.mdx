<Procedure>
<Step title="Open the screen">

**REPORTS → Tableaux d'honneur** (honour rolls).

<DocScreenshot src="web/documents/honour-roll" alt="Honour roll screen: period, class choice, generate button" />

</Step>
<Step title="Choose period and class">

Choose the period in the title, then the class: ModernSchools detects the deserving students.

</Step>
<Step title="Generate">

**Générer Tableau d'Honneur**, then download the file from the box on the right.

</Step>
</Procedure>

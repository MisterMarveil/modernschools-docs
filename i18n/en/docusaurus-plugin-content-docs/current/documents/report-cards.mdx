<Prerequisite>

The period's marks are entered. Check with **État d'insertion des notes** (mark-entry status, Reports, Performances column).

</Prerequisite>

<Procedure>
<Step title="Open generation">

**REPORTS → Bulletins de notes** (report cards).

</Step>
<Step title="Choose period and class">

Choose the period in the title (for example **Trimestre 1**), then the class under **Choisir la classe**. You can also generate a single student's report card.

<DocScreenshot src="web/documents/report-cards" alt="Report card generation: period, class choice, Generate button, file box" />

</Step>
<Step title="Generate">

Click **Générer** (generate), then download the file from the box on the right.

</Step>
</Procedure>

<ExpectedResult>

A PDF holds the class's report cards, with the school's letterhead, logo and signature.

</ExpectedResult>

:::tip
A mark was corrected? Simply regenerate the report card: after **Nettoyer** (clean), the new file replaces the old one in the box.
:::

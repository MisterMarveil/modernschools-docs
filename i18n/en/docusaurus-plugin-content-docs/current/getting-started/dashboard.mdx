## Administrator home

<DocScreenshot src="web/dashboard/admin-home" alt="Administrator home: Reports, Settings, My profile, Logout" />

| Entry | Contents |
|---|---|
| **Reports** | Documents and monitoring: report cards, results sheets, honour rolls, class councils, mark-entry status, statistics, lists, school ID cards, exam photos. |
| **Settings** | Administration: students, users, structure (classes, subjects, periods), assessment grids, settings and [initial setup](/structure/initial-setup). |
| **My profile** | Your profile: name, language, phone, photo, password. |

The flags at the top right switch the application language (French or English).

## Settings

The left menu groups **Users** (Students, User groups, Users), **Structures** (Assessment periods, Class groups, Classes, Week days, Time slots, Subjects, Subject groups), **Assessment grids** and **Configuration**.

<DocScreenshot src="web/dashboard/settings" alt="Settings dashboard with the Initial setup block and the Users, Structures and Assessment grids lists" />

## Reports

The report screens are labelled in French: **Bulletins de notes** (report cards), **Bordereaux de résultats** (results sheets), **Tableaux d'honneur** (honour rolls), **Conseils de classe** (class councils), **Etat d'insertion des notes** (mark-entry status), **Statistiques** (statistics).

<DocScreenshot src="web/documents/reports-home" alt="Reports home: Performances, Secretariat and Factory columns" />

## Teacher home

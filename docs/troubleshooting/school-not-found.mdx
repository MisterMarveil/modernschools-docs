« Trouver mon établissement » n'affiche que les établissements **publiés** par l'équipe BRIDGE.

| Ce que vous voyez | Ce que cela signifie | Que faire |
|---|---|---|
| Aucun résultat | l'école n'est pas encore publiée, ou le nom saisi diffère | essayez le sigle, la ville ou le code de l'école ; sinon, contactez votre administrateur |
| **En préparation** | l'espace de la nouvelle année est en cours de mise en service | patientez : l'adresse s'affichera dès son ouverture |
| **Suspendu** | l'accès est temporairement suspendu | contactez la direction de l'établissement |
| **Archive** | seule une année passée est disponible | voir [les archives](/archives/overview) |
| Service momentanément indisponible | la recherche ne répond pas | réessayez dans quelques minutes ; si vous connaissez l'adresse de votre école, utilisez-la directement |

L'administrateur d'un établissement non publié peut le signaler au [support](/support).

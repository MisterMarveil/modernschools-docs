Les imports sont contrôlés **en entier** : à la moindre erreur, rien n'est enregistré et chaque ligne fautive est indiquée. Corrigez le fichier, puis cliquez de nouveau sur **Contrôler sans importer**.

| Message | Correction |
|---|---|
| Classe inconnue | choisissez la classe dans la liste déroulante du modèle ; ne la tapez pas à la main |
| Champ obligatoire vide | élèves : classe, nom, prénom, sexe ; enseignants : nom, matière, classes |
| Date invalide | format JJ/MM/AAAA, par exemple 05/09/2014 |
| Sexe invalide | M ou F |
| Fichier trop volumineux ou illisible | .xlsx ou .csv, 5 Mo au plus ; repartez du modèle téléchargé |

:::tip
Repartez toujours du **modèle téléchargé depuis votre école** : il contient vos classes et vos matières exactes.
:::

## Les groupes de classes

Les classes sont rangées dans un arbre de **groupes de classes** : l'établissement, puis les cycles, puis les niveaux. Par exemple : *Etablissement* → *1er Cycle* → *6èmes*. Les statistiques et certains documents s'appuient sur cet arbre.

<DocScreenshot src="web/structure/class-groups" alt="Liste des groupes de classes : Etablissement, 1er Cycle, 6èmes, 5èmes, 3èmes, 2nd Cycle, Tles" />

## Les classes

Une **classe** (par exemple *6eme* ou *Tle D*) appartient à un groupe de classes, a une langue par défaut et, au besoin, un code d'examen. Les élèves sont inscrits dans une classe.

## Matières et coefficients

Les **matières** sont regroupées en groupes de matières (littéraires, scientifiques, complémentaires). Le **coefficient** d'une matière dépend de la classe : les mathématiques peuvent compter 4 en 5eme et 5 en Tle D.

## Périodes d'évaluation

L'année (période *Annuelle*) est découpée en trimestres ou en semestres, eux-mêmes évalués par des types d'évaluation : voir [comprendre les périodes](/evaluations/periods).

:::tip Le plus rapide
La [configuration initiale](/structure/initial-setup) crée tout cela d'un coup à partir d'un modèle d'établissement.
:::

<Prerequisite>

Un compte administrateur. Ouvrez **Paramètres**, puis **Configuration initiale → Ouvrir**.

</Prerequisite>

<DocScreenshot src="web/setup/initial-setup" alt="Écran Configuration initiale : modèles d'établissement, classes à cocher, année scolaire, état de l'établissement" />

<Procedure>
<Step title="Choisir le modèle">

Choisissez l'onglet de votre type d'établissement : **Enseignement général**, **Enseignement professionnel** ou **Enseignement technique**. Le modèle indique ses périodes (trimestres ou semestres), ses évaluations et le nombre de matières.

</Step>
<Step title="Cocher les classes">

Cochez les classes de votre établissement, cycle par cycle (**tout cocher** ou **cocher / décocher** un cycle). Les classes déjà créées sont grisées et marquées *déjà créée*.

</Step>
<Step title="Indiquer l'année et créer">

Vérifiez l'**année scolaire** (par exemple 2026-2027), puis cliquez sur **Créer les classes cochées**.

</Step>
</Procedure>

<ExpectedResult>

Un bilan indique ce qui a été créé et ce qui existait déjà. Le cadre **Votre établissement**, à droite, compte classes, matières, coefficients, périodes, créneaux, élèves et enseignants.

</ExpectedResult>

:::info Rien n'est écrasé
Ce qui existe déjà n'est jamais modifié : vous pouvez revenir ajouter des classes. Les coefficients et les dates des périodes se corrigent ensuite dans les menus habituels.
:::

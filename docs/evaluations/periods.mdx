- La période **Annuelle** couvre l'année scolaire.
- Elle a pour **périodes enfants** les trimestres (ou les semestres, selon le modèle choisi).
- Chaque période a une date de début, une date de fin et une **date limite de report des notes** : après cette date, la saisie est close pour les enseignants.
- Les notes sont saisies par **type d'évaluation** (par exemple *Evaluation Harmonisée 1*) au sein d'une période. Les types se gèrent dans **Grilles d'évaluation → Type d'évaluation**.

Les bulletins, procès-verbaux, tableaux d'honneur et conseils de classe se produisent **pour une période**.

**RAPPORTS → Statistiques** ouvre le tableau de bord statistique.

<DocScreenshot src="web/analytics/overview" alt="Tableau de bord statistique : effectif total, répartition par genre et effectifs par classe" />

- Les **filtres** en haut restreignent l'analyse : groupe de classes, enseignant, classe, matière, genre, période ; **Regrouper par** change le regroupement. Cliquez sur **Filtrer** pour appliquer.
- Le menu de gauche ouvre les vues **Stats Générales**, **Effectifs**, **Performances**, **Enseignants**, **Matières** et **Évolution**.
- **Exports** télécharge les données affichées.

Les chiffres portent sur les élèves de l'année en cours ; cochez **Inclure uniquement les élèves actifs** pour écarter les élèves sortis.

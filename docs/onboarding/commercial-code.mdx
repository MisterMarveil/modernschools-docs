Le code commercial rattache votre inscription à l'offre ou au partenaire qui vous l'a communiqué.

<Procedure>
<Step title="Demander un code (si vous n'en avez pas)">

Ouvrez **Demander un code commercial** sur le site officiel. Renseignez votre nom, l'établissement, la ville, le téléphone ou WhatsApp, puis votre besoin. **Ce formulaire ne crée aucune instance** : il enregistre une demande commerciale.

<DocScreenshot src="portal/onboarding/commercial-code" alt="Formulaire Demander un code commercial" />

</Step>
<Step title="Saisir le code dans le dossier">

Dans le [dossier d'inscription](/onboarding/new-school), étape **Offre et conditions**, renseignez le champ **Code commercial**.

<DocScreenshot src="portal/onboarding/step-5-offer" alt="Étape Offre et conditions : offre envisagée et code commercial" />

</Step>
</Procedure>

:::info
Les conditions sont arrêtées avec l'équipe BRIDGE : rien n'est considéré comme payé sur simple déclaration dans le dossier.
:::
